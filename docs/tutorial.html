Prerequisites

NovaGen is a C++17 command-line tool. It only needs to be built once — the projects it generates are plain Python/C++/TypeScript projects you run with your normal tools.

ToolRequired ForNotes
CMake 3.16+Building NovaGencmake --version
C++17 compiler (GCC/Clang/MSVC)Building NovaGenOn Windows, MSYS2 UCRT64 GCC works well
Python 3.8+Running Flask / FastAPI projectsOnly if you use a Python framework
Node.js 16+Running React / Angular frontendsOnly if you generate a frontend
Docker (optional)Containerized deploymentEvery generated project ships a Dockerfile
Windows + MSYS2 note: if the NovaGen compiler or the generated novagen.exe crashes at startup with a DLL error, make sure the MSYS2 UCRT64 bin directory comes first on your PATH. Git's bundled DLLs (libstdc++-6.dll, libgcc_s_seh-1.dll) conflict with the UCRT64 runtime. 
# Windows (PowerShell) — prepend MSYS2 UCRT64 bin
$env:PATH = "C:\msys64\ucrt64\bin;" + $env:PATH

# If CMake can't find pkg-config, point it at the MSYS2 pkgconfig dir
$env:PKG_CONFIG_PATH = "C:\msys64\ucrt64\lib\pkgconfig"

Building NovaGen

Clone or copy the source, then configure and build with CMake:

cd novagen
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j8

The binary is placed at build/novagen.exe (Windows) or build/novagen (Linux/macOS). Verify it works:

./build/novagen.exe --version
# NovaGen v1.0.0 - REST API Generator
Tip: every command below uses ./build/novagen.exe — on Linux/macOS drop the .exe and the leading ./ (or use an alias).

Step 1: Inspect Your Schema

Point NovaGen at any SQL DDL file — MySQL, PostgreSQL, SQLite, T-SQL (SQL Server), or Oracle — and it will tell you exactly which tables and relationships it detected: 

./build/novagen.exe --input schema.sql --list-tables
NovaGen v1.0.0 - crow REST API Generator
Parsing SQL DDL...
Found 13 table(s):
  - Employees (18 columns, 1 FKs)
  - Categories (4 columns, 0 FKs)
  - Customers (11 columns, 0 FKs)
  - Shippers (3 columns, 0 FKs)
  - Suppliers (12 columns, 0 FKs)
  - Orders (14 columns, 3 FKs)
  - Products (10 columns, 2 FKs)
  - Order Details (5 columns, 2 FKs)
  - ...

Primary keys can come from inline column constraints, CONSTRAINT ... PRIMARY KEY (...) clauses, or later ALTER TABLE ... ADD CONSTRAINT ... PRIMARY KEY statements — NovaGen applies all of them, so T-SQL schemas like Northwind parse fully.

Step 2: Generate a Flask API

Generate a complete Flask project with one command:

./build/novagen.exe --input schema.sql --framework flask --output . --project myapi
Generating project: myapi
Output: ".\myapi"
Frontend: react

Project generated successfully!

To run (Flask):
  cd ".\myapi"
  pip install -r requirements.txt
  python run.py

API available at http://localhost:8080/api
Tip: add --frontend none if you only want the API and no frontend directory. Run --help to see all framework and frontend options.

Step 3: Run and Test

Start the server

cd myapi
pip install -r requirements.txt
python run.py

The database file (SQLite) is created automatically on first run under data/.

Step 4: Add a React Frontend

Regenerate with --frontend react (the default) to get a companion <project>-frontend/ directory pre-wired to your API: 

./build/novagen.exe --input schema.sql --framework flask --frontend react \
  --bundler vite --css tailwind --state zustand --project myapi

cd myapi-frontend
npm install
npm run dev
Tip: the generated frontend proxies /api to http://localhost:8080 during development, so the Flask backend and the Vite dev server can run side by side. Full-stack Docker deployment is one command away: docker-compose up --build.

Step 5: The C++ Crow Option

Crow is the default framework — a high-performance C++ backend with zero runtime dependencies:

./build/novagen.exe --input schema.sql --project myapi   # -f crow is default

cd myapi
mkdir build && cd build
cmake .. -DCMAKE_BUILD_TYPE=Release
cmake --build . -j8
./myapi --port 8080

Worked Example: Northwind (T-SQL)

The classic Microsoft Northwind script is real-world T-SQL: quoted identifiers, bracketed [dbo].[Table] names, IDENTITY columns, GO batch separators, and ALTER TABLE ... ADD CONSTRAINT keys. NovaGen handles all of it. 

# 1. Download the Northwind schema
curl -o northwind_schema.sql \
  https://raw.githubusercontent.com/microsoft/sql-server-samples/master/samples/databases/northwind-pubs/instnwnd.sql

# 2. Confirm all 13 tables are detected
./build/novagen.exe --input northwind_schema.sql --list-tables

# 3. Generate the Flask API on your Desktop
./build/novagen.exe --input northwind_schema.sql --framework flask --output . --project northwind

# 4. Run it
cd northwind
pip install -r requirements.txt
python run.py
# Endpoints come from the tables:
GET  /api/categories          # list categories
POST /api/customers           # create a customer (string PK)
GET  /api/customers/ALFKI     # get customer by string PK
GET  /api/products            # list products
GET  /api/orders              # list orders (FKs to customers/employees/shippers)
GET  /api/order-details       # composite-key table "Order Details"
GET  /api/regions             # PK added via ALTER TABLE ... PRIMARY KEY
Note: the schema describes the tables but not the seed data — the generated SQLite database starts empty. Use POST to insert rows, or point the app at your real Northwind database by setting the DATABASE_URL environment variable in config.py.

Troubleshooting

novagen.exe crashes at launch on Windows

Almost always a PATH conflict with Git's runtime DLLs. Prepend the MSYS2 UCRT64 bin directory to PATH before running the build and the generated binary.

CMake fails: "pkg-config not found"

Set PKG_CONFIG_PATH to the MSYS2 pkgconfig directory (see Prerequisites) and make sure pkg-config.exe is on your PATH.

Some tables are missing from --list-tables

Check the DDL: quoted identifiers like [dbo].[Region] are now supported, and ALTER TABLE ... ADD CONSTRAINT ... PRIMARY KEY / FOREIGN KEY statements are applied. If a table still doesn't appear, confirm the statement starts with CREATE TABLE and passes the --list-tables check.

Generated Flask app fails to start

Make sure the data/ directory can be created next to run.py (the app creates it automatically), and that every table has a primary key. Tables without a PK cannot be mapped by SQLAlchemy — add the PK to the DDL.

String primary keys return 404

NovaGen emits the correct Flask route converter (<string:...> for text PKs, <int:...> for numeric ones) automatically. If you see a 404, double-check the exact table path in app/routes/__init__.py.

404 on the frontend dev server

Start the backend first (python run.py on port 8080), then npm run dev. The Vite proxy forwards /api calls to the backend.
