Overview

NovaGen is a code generator that parses SQL DDL (Data Definition Language) and generates complete, production-ready REST API projects. You can choose from multiple backend frameworks and optionally generate a React frontend.

  • ✓ SQL DDL Parsing with FK support
  • ✓ Multiple Backend Frameworks
  • ✓ Optional React Frontend
  • ✓ SQLite Backend
  • ✓ Docker Support
  • ✓ Unit Tests

Backend Frameworks

⚡ Crow (C++)

Fast, lightweight C++ web framework. Header-only with async support. Default choice.

-f crow

🐍 Flask (Python)

Classic Python microframework. Great for simple APIs with Flask-SQLAlchemy.

-f flask

⚡ FastAPI (Python)

Modern Python API framework with automatic OpenAPI docs and Pydantic validation.

-f fastapi

Example: Generate Different Frameworks

# C++ Crow (default)
./novagen --input schema.sql --project myapi

# Python Flask
./novagen --input schema.sql --framework flask --project myapi

# Python FastAPI
./novagen --input schema.sql --framework fastapi --project myapi

Bundlers

Vite (Recommended)

Fast development server and optimized production builds. Modern approach.

CRA (Create React App)

Classic approach. Familiar structure but slower builds.

CSS Frameworks

Tailwind CSS

Utility-first CSS. Highly customizable, small bundle size. Default choice.

Bootstrap

Component-based with React Bootstrap. Familiar API.

Plain CSS

Minimal custom CSS with CSS variables. No framework dependency.

Themes

Light

Default light color scheme.

Dark

Dark mode with manual toggle.

Auto

System preference detection via CSS media query.

State Management

Context API (Default)

React built-in. Simple, no extra dependencies. Uses useReducer.

Zustand

Minimal, hook-based. Simple API with good performance.

Redux Toolkit

Full Redux with slices. Best for complex state needs.

Basic Usage

# C++ Crow backend only
./novagen --input schema.sql --project myapi

# Python Flask backend
./novagen --input schema.sql --framework flask --project myapi

# With React frontend (all defaults)
./novagen --input schema.sql --frontend --project myapi

# Full stack with custom frontend
./novagen --input schema.sql --frontend --bundler cra --css bootstrap --state redux --project myapi

Frontend Examples

# Vite + Tailwind + Light + Context (all defaults)
./novagen --input schema.sql --frontend --project myapi

# Vite + Tailwind + Dark + Zustand
./novagen --input schema.sql --frontend --css tailwind --theme dark --state zustand --project myapi

# CRA + Bootstrap + Dark + Redux
./novagen --input schema.sql --frontend --bundler cra --css bootstrap --theme dark --state redux --project myapi

# Vite + Plain CSS + Auto theme + Context
./novagen --input schema.sql --frontend --css plain --theme auto --project myapi

# Angular with defaults (Esbuild + Tailwind + HttpClient)
./novagen --input schema.sql --frontend angular --project myapi

# Angular + Webpack + Bootstrap + NgRx
./novagen --input schema.sql --frontend angular --angular-bundler webpack --angular-css bootstrap --angular-state ngrx --project myapi

# Angular + Material + Signals + Axios + Guards + Admin
./novagen --input schema.sql --frontend angular --angular-css material --angular-state signals --angular-http axios --guards --admin --project myapi

Examples

Example 1: Basic CRUD API

CREATE TABLE users (
    id INT PRIMARY KEY AUTOINCREMENT,
    name VARCHAR(100) NOT NULL,
    email VARCHAR(255) UNIQUE NOT NULL,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);
# Generate C++ backend only
./novagen --input schema.sql --project basic-api

# Generate with React frontend
./novagen --input schema.sql --frontend --project basic-api

Example 2: E-Commerce with Full Stack

CREATE TABLE customers (
    id INT PRIMARY KEY AUTOINCREMENT,
    name VARCHAR(100) NOT NULL,
    email VARCHAR(255) UNIQUE NOT NULL,
    phone VARCHAR(20)
);

CREATE TABLE products (
    id INT PRIMARY KEY AUTOINCREMENT,
    name VARCHAR(200) NOT NULL,
    price DECIMAL(10,2) NOT NULL,
    stock INT DEFAULT 0
);

CREATE TABLE orders (
    id INT PRIMARY KEY AUTOINCREMENT,
    customer_id INT NOT NULL,
    order_date DATETIME DEFAULT CURRENT_TIMESTAMP,
    status VARCHAR(20) DEFAULT 'pending',
    FOREIGN KEY (customer_id) REFERENCES customers(id)
);

CREATE TABLE order_items (
    id INT PRIMARY KEY AUTOINCREMENT,
    order_id INT NOT NULL,
    product_id INT NOT NULL,
    quantity INT NOT NULL,
    FOREIGN KEY (order_id) REFERENCES orders(id),
    FOREIGN KEY (product_id) REFERENCES products(id)
);
# Generate C++ backend
./novagen --input schema.sql --framework crow --project ecommerce

# Generate Flask backend with React frontend
./novagen --input schema.sql --framework flask --frontend --project ecommerce

# Generate FastAPI backend with React frontend (Vite + Tailwind + Zustand)
./novagen --input schema.sql --framework fastapi --frontend --css tailwind --state zustand --project ecommerce

Example 3: Blog API

CREATE TABLE users (
    id INT PRIMARY KEY AUTOINCREMENT,
    username VARCHAR(50) UNIQUE NOT NULL,
    email VARCHAR(255) UNIQUE NOT NULL,
    password_hash VARCHAR(255) NOT NULL,
    bio TEXT
);

CREATE TABLE posts (
    id INT PRIMARY KEY AUTOINCREMENT,
    title VARCHAR(255) NOT NULL,
    content TEXT NOT NULL,
    author_id INT NOT NULL,
    published BOOLEAN DEFAULT FALSE,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (author_id) REFERENCES users(id)
);

CREATE TABLE comments (
    id INT PRIMARY KEY AUTOINCREMENT,
    post_id INT NOT NULL,
    user_id INT NOT NULL,
    content TEXT NOT NULL,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (post_id) REFERENCES posts(id),
    FOREIGN KEY (user_id) REFERENCES users(id)
);
# Generate with React frontend using CRA + Bootstrap + Redux
./novagen --input schema.sql --framework crow --frontend --bundler cra --css bootstrap --state redux --project blog

Running Generated Projects

C++ Crow Backend

cd myapi
mkdir build && cd build
cmake .. -DCMAKE_BUILD_TYPE=Release
cmake --build . -j$(nproc)
./myapi --port 8080

Python Flask Backend

cd myapi
pip install -r requirements.txt
python run.py

Python FastAPI Backend

cd myapi
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8080 --reload

React Frontend

cd myapi-frontend
npm install
npm run dev

Docker Full Stack

cd myapi-frontend
docker-compose up --build
